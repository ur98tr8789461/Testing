# Sean’s Photography

A responsive photography portfolio built with Node.js and Express.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```sh
npm install
npm run dev
```

Then open <http://localhost:3000>. For a production-style start, run `npm start`. The server uses the `PORT` environment variable when set.

## Customize

- Edit `public/index.html` to update portfolio text, gallery images, and the contact email address.
- Edit `public/styles.css` to adjust the visual design.
- Edit `public/script.js` to change gallery filters and navigation behavior.
